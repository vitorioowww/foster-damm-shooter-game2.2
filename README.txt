========================================================================
   ARCADE SPACE SHOOTER MULTIPLAYER (1v1, 2v2 e 1v1 vs BOT)
========================================================================

Este pacote é 100% gratuito e roda diretamente no navegador via WebRTC (PeerJS).
Não precisa pagar nenhum servidor ou banco de dados!

------------------------------------------------------------------------
🎮 COMO TESTAR LOCALMENTE NO SEU COMPUTADOR:
------------------------------------------------------------------------
1. Extraia o arquivo `.zip` em uma pasta no seu computador.
2. Dê duplo clique no arquivo `index.html` para abrir no seu navegador.
3. Modos disponíveis:
   - [🤖 1v1 vs BOT]: Para testar e jogar sozinho instantaneamente.
   - [⚔️ 1v1 Online]: Para testar com outro computador do lado.
   - [🚀 2v2 Online]: Para jogar em dupla contra outra dupla.

------------------------------------------------------------------------
💻 COMO TESTAR EM 2 COMPUTADORES / ABAS (1v1 ou 2v2):
------------------------------------------------------------------------
1. Abra o `index.html` no Computador A (ou Aba A) e selecione "1v1 Online".
2. Clique em "Copiar Link/Código".
3. No Computador B (ou Aba B na mesma rede/internet), cole o código no campo de entrada e clique em "Entrar na Sala".
4. Assim que os jogadores entrarem nos slots, o botão "INICIAR PARTIDA" ficará ativo para o Host!

------------------------------------------------------------------------
🌐 COMO DEIXAR O SITE 100% GRÁTIS NA INTERNET (Qualquer um pode entrar):
------------------------------------------------------------------------
Você pode hospedar o site em menos de 2 minutos sem pagar nada usando o GitHub Pages ou Vercel:

OPÇÃO 1: GitHub Pages (Mais Fácil e Recomendado)
1. Crie uma conta gratuita em https://github.com
2. Crie um novo repositório público (ex: `meu-jogo-2v2`).
3. Faça upload dos arquivos extraídos deste ZIP (`index.html`, `style.css`, `script.js`).
4. Vá em **Settings** -> **Pages** no seu repositório do GitHub.
5. Em "Source", selecione a branch `main` (ou `master`) e clique em **Save**.
6. Em cerca de 1 minuto, seu site estará ao vivo no link:
   `https://seu-usuario.github.io/meu-jogo-2v2/`

OPÇÃO 2: Vercel / Netlify
1. Acesse https://vercel.com ou https://netlify.com
2. Arraste e solte a pasta com os arquivos do jogo.
3. O site gera um link público grátis instantaneamente!

------------------------------------------------------------------------
🕹️ CONTROLES DO JOGO:
------------------------------------------------------------------------
- Mover para Esquerda: Tecla [A] ou [Seta para Esquerda]
- Mover para Direita: Tecla [D] ou [Seta para Direita]
- Atirar: Tecla [Espaço]
